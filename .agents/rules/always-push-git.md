# Regra: Sempre Enviar Alterações para o GitHub (Git Push)

Sempre que concluir alterações de código, correção de bugs ou novas funcionalidades:

1. Executar `git add .` para incluir todas as modificações e novos arquivos.
2. Criar um commit claro e descritivo em português (ex: `git commit -m "feat: <descrição da funcionalidade>"`).
3. Fazer o push para o repositório remoto no GitHub (`git push`).
4. Informar o usuário confirmando que as alterações foram enviadas para o GitHub com sucesso.

NUNCA finalizar uma tarefa com alterações pendentes sem realizar o `git push`.
