# Regras Internas do Projeto - Daniel Adv Hub

1. **Eyebrows sem travessões**: Nunca usar travessões ou tracinhos em eyebrows/títulos secundários.
2. **Idioma**: Sempre usar Português do Brasil no site, código, banco de dados e SQL (exceto sintaxes/palavras reservadas nativas em inglês).
3. **Citações/Quotes**: Nunca colocar aspas/quotes que não sejam citações reais.
4. **Sem explicações no código**: Não inserir comentários ou frases explicativas sobre funcionamento interno no projeto (ex: "Nessa parte você faz isso"). O projeto é de uso pessoal.
5. **Cópia Local de SQL**: Manter sempre uma cópia atualizada das queries e tabelas em `supabase/schema.sql`. Avisar sempre antes de realizar alterações no SQL do Supabase.
6. **Sincronização com GitHub**: Realizar o versionamento no GitHub (`git add`, `git commit`, `git push`) automaticamente, sem necessidade de autorização prévia.
7. **Segurança**: Garantir que chaves privadas, senhas e variáveis sensíveis fiquem isoladas em `.env.local` e que o `.gitignore` impeça o vazamento para o GitHub.
8. **Comunicação**: Toda a comunicação deve ser estritamente em Português do Brasil.
9. **Confirmação Prévia**: Antes de executar ações de alteração significativa ou criação de código/arquivos não autorizados explicitamente, confirmar com o usuário (exceto comandos do Git).
10. **Stack de Tecnologias**: Antigravity, GitHub, Supabase, Vercel, Cloudflare.
